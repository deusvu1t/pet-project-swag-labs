# QA Automation Pet Project

## 📌 Описание

Автоматизированное тестирование веб-приложения (UI + API).

Проект включает:

* UI тесты (Playwright)
* API тесты (requests)
* Page Object Model (POM)
* Allure отчёты

---

## 🧪 Покрытие тестами

### UI:

* Авторизация (позитивный / негативный кейс)
* Добавление товара в корзину
* Проверка количества товаров

### API:

* GET запрос (получение пользователей)
* POST запрос (создание пользователя)

---

## 🛠️ Стек

* Python
* pytest
* Playwright
* requests
* Allure

---

## ▶️ Запуск тестов

```bash
pytest
```

## 📊 Allure отчёт

```bash
allure serve allure-results
```
